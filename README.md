# 📂 DocFlex

**DocFlex** is a modern and lightweight frontend interface designed for document utilities such as converting, compressing, merging, and managing PDF files.  
This is the **frontend-only version**, and backend integration will be added in future updates.

---

## 🚀 Features (Frontend)
- Clean and modern UI for document tools  
- Responsive design for mobile & desktop  
- Easy drag-and-drop file upload (if added)  
- Simple and intuitive user flow  
- Ready for backend integration

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
